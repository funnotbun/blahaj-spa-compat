# Blåhaj × SmoothPlayerAnimations compatibility patch

Made for:

> [Red's Blåhaj Fork 1.0.2](https://modrinth.com/mod/reds-blahaj-fork/version/1.0.2)

> [SmoothPlayerAnimations 1.0.4+1.21.1](https://modrinth.com/mod/smoothplayeranimations/version/DaX7sMLz)

## Build

Use Java 21, then run `./gradlew build` (`.\gradlew.bat build` on Windows). Gradle downloads NeoForge and compile-only copies of the two target mods from Modrinth. The finished JAR is under `build/libs/`. Neither target mod is packaged into this patch.
